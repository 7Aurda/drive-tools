# Personal Drive Tools

Витрина личного приложения Google OAuth: главная страница и политика
конфиденциальности, которые Google требует для перевода клиента из режима
Testing в production.

Кода здесь нет и не будет — утилиты, которые ходят на Google Drive, живут в
личном репозитории владельца. Этот репозиторий существует ради двух адресов:

- `https://7aurda.github.io/drive-tools/` — homepage URL
- `https://7aurda.github.io/drive-tools/privacy.html` — privacy policy URL

Запрашиваемое разрешение одно: `drive.file`, то есть доступ только к файлам,
созданным самим приложением.
